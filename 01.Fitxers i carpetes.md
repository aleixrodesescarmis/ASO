# Treballar amb fitxers i carpetes

**Situació:** encara no hem estudiat les ordres de PowerShell per treballar amb fitxers i carpetes. Les haurem de descobrir utilitzant les eines d'ajuda de PowerShell.

**1. Buscar ordres**

Busca cmdlets que continguin la paraula `Item`:

```
Get-Command *Item*
```

Observa les ordres que apareixen.

Intenta identificar quina ordre podria servir per:

- crear un element;
- eliminar un element;
- canviar el nom d'un element;
- copiar un element;
- moure un element.

---

| Acció | Cmdlet |
|---|---|
| Crear un element | `New-Item` |
| Eliminar un element | `Remove-Item` |
| Canviar el nom d'un element | `Rename-Item` |
| Copiar un element | `Copy-Item` |
| Moure un element | `Move-Item` |

Aquestes ordres ens permeten gestionar fitxers i carpetes des de PowerShell.

---

**2. Investigar una ordre**

Sense executar-la encara, consulta què fa:

```
Get-Help New-Item
```

Respon:

- Per a què serveix `New-Item`?

Serveix per crear elements nous, com fitxers i carpetes, des de PowerShell.

- Quina estructura té l'ordre?

Té la seguent estructura:

New-Item -Path "ruta" -Name "nom" -ItemType "tipus"

Consulta alguns exemples:

```
Get-Help New-Item -Examples
```

---

**3. Descobrir un paràmetre**

Consulta què significa el paràmetre `-ItemType`:


```
Get-Help New-Item -Parameter ItemType
```
Serveix per indicar el tipus d'element que volem crear, com un fitxer (File) o una carpeta (Directory).


A partir de l'ajuda, intenta descobrir com crear una carpeta.

Per exemple, haurien d'arribar a alguna cosa semblant a:

```
New-Item -ItemType Directory -Name Prova
```

Utilitzem New-Item amb el paràmetre -ItemType Directory per crear una carpeta i -Name per indicar-ne el nom. La comanda quedaria aixi:

New-Item -ItemType Directory -Name Prova

Com la teva.

---

**4. Nou repte**

Ara necessites saber com **canviar el nom de la carpeta**, però no coneixes l'ordre.

Utilitza:

```
Get-Command *Item*
```

i després consulta l'ajuda de l'ordre que creguis adequada.

L'objectiu és arribar a descobrir:

```
Rename-Item
```

i consultar:

```
Get-Help Rename-Item -Examples
```
He acabat trobant l'ordre, la comanda seria: Rename-Item -Path Prova -NewName Prova2

Aquesta comanda canvia el nom de la carpeta Prova a Prova2.

---

Sense utilitzar Internet, descobreix quins cmdlets faries servir per:

1. crear una carpeta;
2. canviar-li el nom;
3. copiar-la;
4. moure-la;
5. eliminar-la.

**Condició:** només pots utilitzar `Get-Command` i `Get-Help` per investigar les ordres.

## Situació

Estàs administrant un servidor Windows i necessites consultar informació de la seva configuració de xarxa.

Encara no coneixes les ordres de PowerShell relacionades amb xarxa.

La teva feina és descobrir-les utilitzant principalment:

```
Get-Command
Get-Help
```

No pots buscar les respostes a Internet.

---

## Tasques

Descobreix quines ordres de PowerShell et permeten obtenir la informació següent:

1. Mostrar els adaptadors de xarxa de l’equip.      
2. Consultar les adreces IP configurades.      
3. Consultar la configuració IP completa dels adaptadors de xarxa.      
4. Consultar els servidors DNS configurats.      
5. Comprovar si hi ha connectivitat amb un altre equip de la xarxa.  

---
## Per cada tasca

Indica:

- el cmdlet que has trobat;      
- com l’has localitzat amb `Get-Command`;  
- una breu explicació del que fa;  
- la comanda que has executat;  
- el resultat obtingut.  

L'objectiu és que hi hagi una traçabilitat de com s'ha arribat a la comanda final.

### 1. Mostrar els adaptadors de xarxa
- **Cmdlet:** Get-NetAdapter
- **Cerca:** Get-Command *NetAdapter*
- **Ajuda:** Get-Help Get-NetAdapter
- **Funció:** Mostra els adaptadors de xarxa de l'equip, el seu nom, l'estat de la connexió i la velocitat.
- **Comanda executada:** Get-NetAdapter
- **Resultat obtingut:** Apareix una llista dels adaptadors de xarxa amb informació sobre el seu estat i la velocitat de connexió.

### 2. Consultar les adreces IP
- **Cmdlet:** Get-NetIPAddress
- **Cerca:** Get-Command *NetIPAddress*
- **Ajuda:** Get-Help Get-NetIPAddress
- **Funció:** Permet consultar les adreces IPv4 i IPv6 configurades als diferents adaptadors de xarxa.
- **Comanda executada:** Get-NetIPAddress
- **Resultat obtingut:** Es mostren les adreces IP configurades i informació sobre l'adaptador al qual pertany cadascuna.

### 3. Consultar la configuració IP completa
- **Cmdlet:** Get-NetIPConfiguration
- **Cerca:** Get-Command *NetIPConfiguration*
- **Ajuda:** Get-Help Get-NetIPConfiguration
- **Funció:** Mostra informació detallada de la configuració de xarxa, com ara les adreces IP, la porta d'enllaç i els servidors DNS.
- **Comanda executada:** Get-NetIPConfiguration -Detailed
- **Resultat obtingut:** Apareix la configuració detallada dels adaptadors, incloent-hi les adreces IP, la porta d'enllaç i els DNS.

### 4. Consultar els servidors DNS
- **Cmdlet:** Get-DnsClientServerAddress
- **Cerca:** Get-Command *DnsClientServerAddress*
- **Ajuda:** Get-Help Get-DnsClientServerAddress
- **Funció:** Mostra els servidors DNS configurats a cada adaptador, que permeten traduir els noms de domini en adreces IP.
- **Comanda executada:** Get-DnsClientServerAddress
- **Resultat obtingut:** Es mostra una llista dels adaptadors de xarxa amb les adreces dels servidors DNS que tenen configurats.

### 5. Comprovar la connectivitat
- **Cmdlet:** Test-Connection
- **Cerca:** Get-Command *Connection*
- **Ajuda:** Get-Help Test-Connection
- **Funció:** Comprova si un altre equip de la xarxa respon enviant-li paquets de prova i mesura el temps de resposta.
- **Comanda executada:** Test-Connection -ComputerName 192.168.1.1 -Count 4
- **Resultat obtingut:** Es mostra si l'equip de destinació respon a les proves de connexió i, si respon, el temps que triga.
